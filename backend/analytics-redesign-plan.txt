ANALYTICS REDESIGN PLAN
=======================

STRUCTURE
---------
Top bar: [Agent Selector ▼] [Refresh]
Tabs: [Overview] [Conversations] [Knowledge] [Costs]

OVERVIEW TAB
------------
4 KPI Cards:
- Total Conversations (count, +/- % vs last period if available)
- RAG Hit Rate (% queries with chunks_found > 0)
- Avg Response Time (seconds, color: <3s green, 3-5s yellow, >5s red)
- Total Cost ($USD)

2 Charts:
- Timeline: Conversations per day (last 30 days) - ApexCharts line
- Intent Distribution: Pie/donut chart

RAG Health Summary Card:
- Hit rate: X% (N/Total queries found chunks)
- Avg similarity: X%
- Failed retrievals: N queries with 0 chunks

CONVERSATIONS TAB
-----------------
Existing DataGrid enhanced with:

New Columns:
- RAG Quality: ✓ (>70%), ~ (50-70%), ✗ (<50% or 0 chunks)
- Duration: color-coded (<3s green, 3-5s yellow, >5s red)

Expandable Row (3-panel layout):
Left Panel - Conversation:
  - Full message
  - Full response
  - Intent + confidence

Center Panel - Agent Pipeline:
  - Vertical timeline showing 4 agents
  - Each agent: name, duration, tokens (input→output)
  - Status icon per agent

Right Panel - RAG Chunks:
  - List of retrieved chunks
  - Each chunk: title, category badge, similarity bar
  - [View Full] button

KNOWLEDGE TAB
-------------
Top Stats Card:
- Total queries | With chunks (X%)
- Avg similarity | Median similarity
- Top categories used

Sub-tabs: [Failed Retrievals] [Low Similarity] [All Queries]

DataGrid columns:
- Query text
- Chunks found
- Avg similarity
- Max similarity
- Categories
- [+ Add Knowledge] button (for failed queries)

Similarity Distribution Histogram:
- 0-30%, 30-50%, 50-70%, 70-90%, 90-100%
- Show count per bucket

COSTS TAB
---------
3 KPI Cards:
- Total cost
- This month cost
- Avg per query

Cost Over Time Chart:
- Daily breakdown (last 30 days)

Cost Breakdown (2 sections):
1. By Intent: list with $ and %
2. By Agent: list with $ and %

Most Expensive Queries Table:
- Top 10 by estimated_cost_usd

AGENT SELECTOR
--------------
- Dropdown in top-right
- Filters all tabs to selected agent_id
- "All Agents" option for aggregate view
- State persisted in URL params: ?agent_id=1&tab=conversations
- API calls include agent_id filter

DATA STRUCTURE (from token_details)
------------------------------------
intent_classifier: {input, output, total}
knowledge_retriever: {
  embedding_tokens,
  chunks_found,
  avg_similarity,
  max_similarity,
  categories: [],
  chunks: [{id, title, similarity, category}]
}
response_generator: {input, output, total}
memory_saver: {input, output, total, note: "estimated"}
