EXTRACTION PROMPT (NEW)
-----------------------
Input: message + history + rag_hints
Output: search_query (string)

Prompt:
"""
Gere uma query de busca semântica para encontrar informações relevantes.

## O QUE EXISTE NA BASE DE CONHECIMENTO
{rag_hints}

## HISTÓRICO
{recent_history}

## MENSAGEM ATUAL
{message}

Gere uma query rica que capture o que o cliente quer saber.
Resolva pronomes usando o histórico. Use termos que existem na base.
"""

AUTO-GENERATE OPTIONS (TBD)
---------------------------

BENEFITS
--------
- Simpler extraction (~200 tokens vs ~500)
- No config dependency (traits/intents)
- Domain-adaptive (hints from actual content)
- User maintains descriptions (knows their data)

TRADE-OFFS
----------
- Lose explicit escalation rules → LLM decides
- Lose intent analytics → could add back via post-hoc classification
- User must describe files → mitigated by auto-generate option
