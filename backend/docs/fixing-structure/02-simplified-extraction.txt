SIMPLIFIED v3 AGENT ARCHITECTURE
=================================
Date: 2025-11-26

SUMMARY
-------
Removed extraction LLM call. Search query now built from message + conversation history.
Tested: 2 turns of context gives +15% RAG improvement. Free (no LLM call).

CHANGES MADE
------------
1. REMOVED:
   - extract.py (entire file)
   - generate.py (entire file)
   - execute.py (entire file)
   - ExtractionResult class
   - Trait, IntentType, ObjectionType classes
   - ExtractionConfig class
   - traits, intents, objection_types from config

2. SIMPLIFIED:
   - schema.py: Only core types remain (Objective, Event, Guardrails, etc.)
   - config.py: Removed extraction config, added RAGConfig with context_turns
   - prompts.py: Only generation prompt, escalation in prompt
   - AssembleResult: Removed examples field

3. NEW FLOW:
   Old: extract → check_escalation → assemble → agent → tools → validate → post_process
   New: assemble → agent ⟷ tools → post_process

4. SEARCH QUERY:
   - Built from: message + last 2 turns of history
   - Method: AgentState.build_search_query(message, context_turns=2)
   - No LLM call needed

5. ESCALATION:
   - Moved to generation prompt
   - LLM evaluates user-defined conditions
   - EscalationTrigger.condition is human-readable text

RAG TESTING RESULTS
-------------------
Query: "tem garantia?"

Sweet spot: 2 turns. Diminishing returns after.
