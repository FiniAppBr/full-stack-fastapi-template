  RESUME OF DISCUSSION

  What We're Building

  A visual flow builder for configuring AI agents with a pipeline architecture that matches the actual backend implementation.

  Current Pipeline (What exists in code)

  1. Input (WhatsApp) → 2. Conhecimento (RAG) → 3. Coleta de Dados (Custom fields) → 4. Personalidade (Tone/Multi-turn) → 5. Validação (Response validation) → 6. Output (WhatsApp)

  Missing Pipeline Nodes

  - Memória node (long-term memory config, goes after Validação)

  Configuration Attachments (Side nodes)

  - FilterNode → connects to Conhecimento (gating_rules)
  - CorrectionsNode → connects to Validação (validation_rules) [CURRENTLY WRONG, connects to Personalidade]
  - FilesNode → connects to Coleta de Dados (media_rules) [CURRENTLY WRONG, connects to Output]
  - StyleNode → connects to Personalidade (multi_turn_config)

  Add Buttons

  Each pipeline node has an Add button that:
  - Opens a drawer/form to manually configure that stage
  - Alternative to chat-based configuration
  - Changes reflect in both interfaces

  Key Insights from Móveis Agent

  1. Gating rules filter knowledge BEFORE retrieval (if budget=unknown → exclude pricing tags)
  2. Media rules use keyword triggers in AI response (mentions "luxury" → send premium PDF)
  3. Validation rules check/modify AFTER generation (if budget=unknown but response has "R$" → strip prices)
  4. Custom fields track conversation state (budget_range, lead_quality, contact_captured)
  5. Multi-turn splits messages into separate sends

  Key Design Questions Resolved

  1. Field-based media triggers are desired (if budget_range=20k_plus → send PDF)
  2. Response schema should be dynamically generated from rules/triggers (not manually configured)
  3. CorrectionsNode must connect to Validação (not Personalidade)
  4. Memory config needs to be added as pipeline node
  5. Actions/Tools not implemented yet (future)

  Immediate Fixes Needed

  1. Move CorrectionsNode edge from Personalidade → Validação
  2. Move FilesNode edge from Output → Coleta de Dados
  3. Add Memória pipeline node between Validação and Output
  4. Ensure Add buttons are properly wired to open config drawers
