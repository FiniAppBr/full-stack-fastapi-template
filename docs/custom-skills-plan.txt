Based on skill-creator analysis and ConnectAI architecture


SKILL CREATION PROCESS (from skill-creator)
============================================

1. Understand skill with concrete examples
2. Plan reusable contents (scripts/references/assets)
3. Initialize skill (using init_skill.py)
4. Edit SKILL.md (imperative/infinitive form)
5. Package skill (using package_skill.py)
6. Iterate based on usage

## FRONTEND DEVELOPMENT SKILLS
===============================

### 1. react-flow-node-builder
Priority: HIGH
Status: Plan

**Purpose:**
Create custom React Flow node components following ConnectAI patterns

**When to use:**
When user needs to create or modify node types in the flowchart builder
(AgentNode, StageNode, StartStageNode, EndStageNode, etc.)

**Reusable contents:**
- scripts/
  - generate_node_component.py - Generate boilerplate node component

- references/
  - node-patterns.md - Common node patterns (expandable, connectable)
  - styling-guide.md - MUI styling conventions
  - react-flow-api.md - React Flow specific APIs

- assets/
  - templates/
    - BaseNode.jsx - Base node template
    - ExpandableNode.jsx - Stage node template
    - SimpleNode.jsx - Agent/End node template

**Workflow:**
1. Ask user: node type, expandable?, handles configuration
2. Generate component from template
3. Add to nodeTypes in flowchart-builder-view.jsx
4. Generate styles based on MUI theme

### 3. flowchart-validator
Priority: HIGH
Status: Plan

**Purpose:**
Validate flowchart structure for completeness and correctness

**When to use:**
Before saving flowcharts or when user requests validation

**Reusable contents:**
- scripts/
  - validate_flow.py - Validation logic
    • Check for orphaned nodes
    • Detect circular dependencies
    • Verify all stages have transitions
    • Ensure START and END stages exist
    • Validate connection rules

- references/
  - validation-rules.md - All validation rules
  - error-messages.md - User-friendly error descriptions

**Workflow:**
1. Parse flowchart nodes and edges
2. Run validation checks
3. Return structured errors with fixes
4. Suggest corrections

### 7. ai-orchestration-helper
Priority: VERY HIGH
Status: Plan

**Purpose:**
Build the AI conversation orchestration logic (core feature)

**When to use:**
When implementing stage transitions, variable extraction, LLM calls

**Reusable contents:**
- scripts/
  - orchestrate_conversation.py - Main orchestration logic
  - evaluate_transition.py - Transition condition evaluator
  - extract_variables.py - Data extraction from messages

- references/
  - claude-api.md - Anthropic Claude API patterns
  - structured-output.md - How to get structured responses
  - prompt-templates.md - System prompts for different stages
  - variable-extraction.md - Patterns for extracting data

- assets/
  - prompts/
    - base_agent_prompt.txt
    - stage_prompt_template.txt
    - transition_evaluator_prompt.txt
    - variable_extractor_prompt.txt

**Workflow:**
1. Load flowchart structure
2. Get current stage configuration
3. Build AI context (personality + stage + knowledge + history)
4. Call LLM with structured output
5. Extract variables from response
6. Evaluate transition conditions
7. Update conversation state
8. Return response to customer

## SKILL STRUCTURE TEMPLATE
============================

Each skill will have:

```
skill-name/
├── SKILL.md                  # Main instructions
│   ├── YAML frontmatter
│   │   ├── name: skill-name
│   │   └── description: When to use this skill
│   └── Instructions (imperative form)
│
├── scripts/                  # Executable Python/Bash
│   └── example_script.py
│
├── references/               # Documentation (loaded as needed)
│   └── patterns.md
│
└── assets/                   # Templates/boilerplate
    └── templates/
        └── example.jsx
```

## SKILL DEVELOPMENT WORKFLOW
==============================

For each skill:

1. Use skill-creator to initialize:
   ```bash
   python .claude/skills/skill-creator/scripts/init_skill.py <skill-name> --path .claude/skills/
   ```

2. Populate with ConnectAI-specific content

3. Test in real development scenarios

4. Package:
   ```bash
   python .claude/skills/skill-creator/scripts/package_skill.py .claude/skills/<skill-name>
   ```

5. Share with team (if applicable)
