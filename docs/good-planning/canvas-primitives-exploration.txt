ConnectAI - Canvas Primitives & Building Blocks
================================================

CORE INSIGHT:
-------------
The canvas is a BUILDER INTERFACE where you assemble building blocks.
Like Webflow, Notion, or Airtable - you're not coding, you're composing.


LEFT DRAWER: THE TOOLBOX
-------------------------

Instead of dragging random files into void, you have a PALETTE of things you can add.

PRIMITIVES (The Raw Materials):
--------------------------------

**TEXT**
Click → Dialog:
```
┌─────────────────────────────┐
│  Add Text Block             │
├─────────────────────────────┤
│  Name: [Business Hours    ] │
│                             │
│  Content:                   │
│  ┌─────────────────────────┐│
│  │ Monday-Friday: 9am-6pm  ││
│  │ Saturday: 10am-4pm      ││
│  │ Sunday: Closed          ││
│  └─────────────────────────┘│
│                             │
│  [Cancel]  [Add to Canvas]  │
└─────────────────────────────┘
```
Appears on canvas as:
```
┌──────────────────┐
│ 📝 Business Hours│
│ Mon-Fri: 9am-6pm │
│ [Expand] [Edit]  │
└──────────────────┘
```

**DOCUMENT**
Click → File picker → Upload PDF/DOCX → AI analyzes:
```
┌────────────────────────────┐
│  I found this in your doc: │
├────────────────────────────┤
│  • 12 service prices       │
```

THE CANVAS ITSELF:
------------------

Once you add blocks, they appear on canvas as CARDS.

You can:
- Drag to rearrange
- Click to edit
- Delete
- Duplicate
- Connect (optional - shows relationships)

**Example Canvas for Restaurant:**
```
┌─────────────┐  ┌────────────┐  ┌───────────────┐
│ 🎭 Personality│  │ 📋 Menu    │  │ 📅 Reservations│
│ Warm, Friendly│  │ 45 items   │  │ Google Sheet  │
└─────────────┘  └────────────┘  └───────────────┘

┌─────────────┐  ┌────────────┐  ┌───────────────┐
│ 📸 Gallery  │  │ 📝 Hours   │  │ ⚠️ Handoff    │
│ 12 photos   │  │ Tue-Sun    │  │ On complaint  │
└─────────────┘  └────────────┘  └───────────────┘

┌─────────────────────────────┐
│ 💬 Quick Replies            │
│ • No delivery, pickup only  │
│ • Gluten-free pasta avail.  │
└─────────────────────────────┘
```

**Visual Organization Ideas:**

**Option A: Freeform (like Miro)**
- Drag anywhere
- Group related cards
- Draw areas/boxes around groups

**Option B: Sections (like Notion)**
- Cards auto-organize into sections
- Sections: Knowledge, Actions, Behavior, Integrations
- Can collapse sections

**Option C: Layers (like Figma)**
- Background layer: Static info (menu, hours)
- Middle layer: Actions (booking, forms)
- Top layer: Behavior (personality, rules)

**Option D: List View Toggle**
- Canvas view: Visual/spatial
- List view: Organized by type
- Toggle between them


WHY THIS STRUCTURE WORKS:
--------------------------

1. **Clear Categories**
   - Primitives: Basic building blocks
   - Content: Business-specific stuff
   - Actions: Things AI can DO
   - Behavior: How AI acts
   - Data: What to remember
   - Integrations: External connections

2. **Progressive Complexity**
   - Start simple: Add text, upload doc
   - Get fancy: Add forms, custom rules
   - Go advanced: API integrations, complex logic

3. **Familiar Patterns**
   - Drawer of tools (Figma, Canva)
   - Click to configure (Webflow, Notion)
   - Cards on canvas (Trello, Miro)

4. **Guided but Flexible**
   - Drawer shows what's possible
   - But doesn't force a sequence
   - Add what you need, skip what you don't

5. **Visual Inventory**
   - Canvas shows "what my AI knows"
   - Can see at a glance what's missing
   - Easy to add/edit/remove


INTERACTION FLOWS:
------------------

**Setup Flow 1: Law Firm (10 min)**

1. Sign up → Blank canvas
2. Click "🎭 Personality" in drawer
   - Set professional tone, no emojis, PT/EN
3. Click "👤 Professional" three times
   - Add Maria, João, Ana with specialties
4. Click "📄 Document"
   - Upload price-list.pdf → AI creates pricing cards
5. Click "🔗 Calendar"
   - Connect Google Calendar

   - Configure consultation booking
7. Click "⚠️ Handoff"
   - Set escalation rules

ADVANCED: CONNECTING BLOCKS
----------------------------

For power users, can draw connections to show relationships:

```
[Menu] ─────→ [Payment]
          ↓
    [Appointment] ──→ [Calendar]
          ↓
    [Notification] ──→ [Slack]
```

This shows:
- Menu items can be purchased (payment flow)
- Appointments check calendar availability
- New appointments notify Slack

BUT this is optional. AI infers relationships automatically.
Connections are for user's mental model / documentation.

MY GUT FEELINGS:
----------------

**What excites me:**

1. **The "Customer" block is genius**
   - Every business has unique customer data
   - Auto-customizing the CRM to their needs
   - AI asks for it naturally in conversation
   - This could be a HUGE differentiator

2. **Behavior blocks (personality, response style, audio)**
   - These are hard to expose in traditional UIs
   - But as "blocks" they feel tangible and editable
   - Love the idea of sliders for tone

3. **The drawer giving structure**
   - Blank canvas is intimidating
   - Drawer says "here are your options"
   - But doesn't force a sequence

4. **Primitives + Specialized makes sense**
   - Start with basics (text, doc, image)
   - Level up to specialized (product, professional)
   - Natural progression

**What worries me:**

1. **Is canvas necessary or just cool?**
   - Could this be a LIST of cards instead?
   - What does spatial arrangement actually enable?
   - Maybe canvas is for "Phase 2" complexity

2. **Too many block types?**
   - 15+ different blocks might overwhelm
   - Need smart defaults/templates
   - "Start from template" might be better entry

3. **The abstraction layer**
   - User adds blocks
   - But they're really training an AI agent
   - Does the metaphor hold?

4. **Configuration dialogs can get complex**
   - That "Appointment" dialog has a lot of options
   - Need progressive disclosure within dialogs too


ALTERNATIVE: START SIMPLER
---------------------------

What if Phase 1 is NOT a canvas, but a WIZARD:

1. "What does your business do?" (text)
2. "Upload your business documents" (files)
3. "How should your AI sound?" (sliders)
4. "Connect your tools" (OAuth buttons)
5. "When should AI hand off to human?" (checkboxes)

Takes 5 minutes. AI is live.

Then: "Want to customize? Open Builder" → THAT'S the canvas.

Builder is for:
- Adding more sophisticated blocks
- Custom rules and logic
- Fine-tuning behavior
- Advanced integrations

This way:
- Beginners: Never see canvas, just wizard
- Intermediate: Use canvas to add specific blocks
- Advanced: Full control with custom rules


FINAL TAKE:
-----------

The BLOCK CONCEPT is solid.
The DRAWER STRUCTURE makes sense.
The CUSTOMER BLOCK is innovative.

The question is: Does it need to be on a CANVAS?

Or could it be:
- A vertical list of cards (Notion-style)
- Organized tabs (Knowledge, Actions, Behavior)
- A step-by-step builder
- Or... does the canvas unlock something unique?

The canvas shines if:
- Spatial arrangement has meaning
- Connections between blocks matter
- Visual overview is valuable
- It feels fun/engaging to use

The canvas fails if:
- It's just decoration
- List view would be faster
- Adds complexity without benefit

My gut: TRY THE CANVAS for beta.
If users love it → keep it.
If users ignore spatial features → switch to list.
If users get confused → add wizard first.

Let's not overthink without user feedback.
Build, test, iterate.
