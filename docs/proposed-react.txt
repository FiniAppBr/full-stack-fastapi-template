AGENT MODEL FIELDS (NEW)
------------------------
- tone: str ("professional", "friendly", "energetic")
- language: str ("pt", "en", "both")
- emoji_usage: str ("none", "minimal", "frequent")
- stages_enabled: bool
- stages: JSON (list of ConversationStage)
- enabled_tools: JSON (list of tool names)
- tool_configs: JSON (per-tool settings)
- handoff_triggers: JSON (list of trigger words)
