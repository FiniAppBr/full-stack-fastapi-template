ConnectAI - Builder AI Assistant Concept
==========================================

THE CONCEPT:
------------
Split-screen interface:

LEFT: Notion-style block list (the configuration)
RIGHT: Chat with Builder AI (the assistant that helps you configure)

You can:
- Chat with the AI: "I need my bot to handle appointment booking"
- Drag files into the chat: Drops price-list.pdf → AI processes it
- AI creates blocks for you on the left automatically
- You can also manually add/edit blocks directly on the left

It's like having a consultant help you set up your AI agent.

HOW IT WORKS: Behind the Scenes
--------------------------------

**Builder AI is a specialized LLM agent with tools:**

1. **Question Tool**: Ask user for info
2. **FileParser Tool**: Process uploaded documents
3. **BlockCreator Tool**: Create blocks in left panel
4. **Integration Tool**: Trigger OAuth flows
5. **Validator Tool**: Check if setup is complete

**Builder AI's System Prompt (simplified):**
```
You are helping a business owner set up their AI customer service agent.

Your goal: Gather the information needed to create a working AI in under 10 minutes.

You must collect:
1. Business type and what AI should handle
2. Knowledge (price lists, services, FAQs, team info)
3. Tone/personality
4. Actions (appointments, payments, forms)
5. Handoff rules (when to escalate to human)
6. Integrations (calendar, email, etc)

Be conversational and guide them step by step.
When they give you information or upload files, use the BlockCreator tool
to add blocks to their configuration.

Be encouraging and make it feel easy.
```

**Example Tool Calls:**

User says: "Maria - work visas, João - family visas, Ana - student visas"

Builder AI thinks:
```
User provided team info. Create professional blocks.

BlockCreator(
  type="professional",
  data=[
    {name: "Dr. Maria Santos", specialty: "Work Visas"},
    {name: "Dr. João Silva", specialty: "Family Visas"},
    {name: "Dr. Ana Costa", specialty: "Student Visas"}
  ]
)
```

→ Three "Professional" blocks appear on left panel.

User drags pricing.pdf:

Builder AI thinks:
```
FileParser(file="pricing.pdf")
→ Extracted: 12 services with prices

BlockCreator(
  type="pricing",
  data={
    services: [...12 services with prices...]
  }
)
```

→ "Pricing" block appears on left panel.

TECHNICAL IMPLEMENTATION:
--------------------------

**Frontend:**
- Split screen: Blocks list (left) + Chat (right)
- Blocks: React component with sections (Knowledge, Actions, Behavior, etc.)
- Chat: Standard chat UI with file drop zone
- Real-time updates: When Builder AI creates block, it appears on left

**Backend:**
- Builder AI: GPT-4 with function calling
- Tools: BlockCreator, FileParser, IntegrationManager, Validator
- Conversation stored: Can resume later, AI remembers what you've configured
- File processing: Parse PDFs/DOCX/XLSX → Extract structured data

**Builder AI Functions:**
```python
@function
def create_block(type: str, data: dict):
    """Create a configuration block"""
    # Validates data
    # Creates block in database
    # Sends to frontend to display
    return {"success": True, "block_id": "..."}

@function
def parse_file(file: File):
    """Parse uploaded file and extract data"""
    # Uses AI + parsing libraries
    # Returns structured data
    return {"type": "pricing", "items": [...]}

@function
def connect_integration(service: str):
    """Initiate OAuth flow for integration"""
    # Returns OAuth URL
    return {"oauth_url": "https://..."}

@function
def get_configuration_status():
    """Check what's been configured and what's missing"""
    return {
        "complete": ["knowledge", "personality"],
        "missing": ["calendar", "handoff_rules"]
    }
```

POTENTIAL CONCERNS:
-------------------

**1. Is chat actually faster than a form?**
- Forms: User has to read all fields, decide what to fill
- Chat: AI asks one question at a time, user just answers
- Chat is cognitively easier, even if similar time

**2. Will users trust the AI to configure correctly?**
- They can see blocks being created in real-time (left panel)
- They can edit blocks directly
- They can test before going live
- Transparency builds trust

**3. What if Builder AI asks wrong questions or misunderstands?**
- User can correct: "No, I meant..."
- User can manually edit blocks
- Builder AI can be improved over time with feedback

**4. Is this too "magical"? Does it feel like loss of control?**
- Left panel shows exactly what's configured
- User can edit anything manually
- Chat is optional - can build purely with blocks if preferred
- Magic with transparency = good UX
