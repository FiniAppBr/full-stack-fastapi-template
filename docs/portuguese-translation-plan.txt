IMPLEMENTATION STEPS
--------------------

Step 1: Add pt-BR to MUI Locales
---------------------------------
File: /src/locales/all-langs.js

Import MUI Portuguese locales:
```javascript
import { ptBR as ptBRCore } from '@mui/material/locale';
import { ptBR as ptBRDate } from '@mui/x-date-pickers/locales';
import { ptBR as ptBRDataGrid } from '@mui/x-data-grid/locales';
```

Add to allLangs array:
```javascript
{
  value: 'pt-br',
  label: 'Português (Brasil)',
  countryCode: 'BR',
  adapterLocale: 'pt-BR',
  numberFormat: { code: 'pt-BR', currency: 'BRL' },
  systemValue: {
    components: {
      ...ptBRCore.components,
      ...ptBRDate.components,
      ...ptBRDataGrid.components
    },
  },
}
```
