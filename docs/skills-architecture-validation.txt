OFFICIAL SKILL ARCHITECTURE (from agent_skills_spec.md + examples)
===================================================================

REQUIRED STRUCTURE:
```
skill-name/              # Must match YAML name field
├── SKILL.md            # REQUIRED - only file that MUST exist
│   ├── YAML frontmatter (required)
│   │   ├── name: skill-name (required, hyphen-case, matches folder)
│   │   └── description: (required, when Claude should use it)
│   │   └── license: (optional)
│   │   └── allowed-tools: (optional, for Claude Code)
│   │   └── metadata: (optional, key-value pairs)
│   └── Markdown body (no restrictions)
```

OPTIONAL ADDITIONS (based on skill-creator patterns):
```
├── scripts/            # Executable code (Python/Bash/etc.)
├── references/         # Documentation (loaded as needed)
├── assets/             # Templates/files for output
└── examples/           # Example usage (seen in webapp-testing)
```

ARCHITECTURE BEST PRACTICES WE'RE FOLLOWING
============================================

1. ✓ Progressive Disclosure
   - Metadata always loaded (~100 words)
   - SKILL.md loaded when triggered (<5k words)
   - Bundled resources loaded as needed

2. ✓ Separation of Concerns
   - Scripts: Executable, deterministic code
   - References: Documentation loaded on-demand
   - Assets: Templates for output (not loaded into context)

3. ✓ Avoid Duplication
   - References files for detailed info
   - SKILL.md only for essential procedural instructions

4. ✓ Token Efficiency
   - Large files in references/ (not SKILL.md)
   - Scripts can execute without reading
   - Assets used without loading

5. ✓ Clear Triggering
   - Descriptions specify exactly when to use skill
   - Third-person voice ("This skill should be used when...")

   - Would be useful for ai-orchestration-helper

3. Consider 'metadata' field for versioning
   - Track skill versions
   - ConnectAI version compatibility

4. Add LICENSE.txt to each skill
   - Follow pattern from official skills
   - Apache 2.0 recommended


RECOMMENDED YAML FRONTMATTER TEMPLATE
======================================

For our ConnectAI skills:

```yaml
---
name: skill-name-here
description: This skill should be used when [specific scenario]. [What it does].
license: Apache-2.0 (see LICENSE.txt)
allowed-tools:
  - Read
  - Write
  - Bash
metadata:
  version: "1.0.0"
  connectai-version: ">=0.1.0"
  category: "frontend" # or "backend" or "fullstack"
---
```
