CREWAI IMPLEMENTATION FOR OUR WORKFLOW

```python
from crewai import Agent, Task, Crew, Process
from langchain_openai import ChatOpenAI
import instructor
from pydantic import BaseModel

# LLM
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

# Define our agents
structure_detector = Agent(
    role="Document Structure Detector",
    goal="Analyze document content and identify type (pricing_table, faq, menu, etc.)",
    backstory="Expert at understanding document structures and entities",
    llm=llm,
    verbose=True
)

data_normalizer = Agent(
    role="Data Normalizer",
    goal="Clean and standardize text (Unicode fixes, currency formatting, whitespace)",
    backstory="Specialist in text preprocessing and normalization",
    llm=llm,
    verbose=True
)

conflict_checker = Agent(
    role="Conflict Detector",
    goal="Compare new data with existing knowledge blocks and find contradictions",
    backstory="Meticulous analyst who never misses inconsistencies",
    llm=llm,
    verbose=True,
    tools=[deepdiff_tool, postgres_query_tool]  # Custom tools
)

variant_generator = Agent(
    role="Natural Language Variant Generator",
    goal="Generate 5 natural language versions of structured data for better search",
    backstory="Creative linguist fluent in Brazilian Portuguese",
    llm=llm,
    verbose=True
)

# Define tasks
task1 = Task(
    description="""
    Analyze this document content and determine:
    - Document type (pricing_table, faq, menu, policy, schedule)
    - Key entities (services, products, etc.)
    - Confidence score

    Document: {document_content}
    """,
    agent=structure_detector,
    expected_output="JSON with doc_type, entities, confidence"
)

task2 = Task(
    description="""
    Normalize and clean this text:
    - Fix Unicode/encoding issues
    - Standardize currency (R$ 60,00 → R$60)
    - Clean whitespace
    - Standardize date formats

    Text: {document_content}
    """,
    agent=data_normalizer,
    expected_output="Cleaned, normalized text"
)

task3 = Task(
    description="""
    Check for conflicts with existing knowledge:
    1. Query PostgreSQL for existing blocks (agent_id: {agent_id})
    2. Compare new data vs existing using DeepDiff
    3. Identify contradictions (price changes, policy updates, etc.)
    4. Determine if user input needed

    New data: {normalized_data}
    Structure: {structure}
    """,
    agent=conflict_checker,
    expected_output="JSON with has_conflicts, conflicts list, needs_user_input",
    context=[task1, task2]  # Depends on tasks 1 & 2
)

task4 = Task(
    description="""
    Generate 5 natural language variants for search:

    Input data: {normalized_data}

    Examples:
    - "Banho para cachorro pequeno custa R$60"
    - "Para cães pequenos, o banho sai R$60"
    - "Quanto custa banho? R$60 pra cachorro pequeno"

    Generate variants in Brazilian Portuguese.
    """,
    agent=variant_generator,
    expected_output="List of 5 natural language variants",
    context=[task2, task3]  # Depends on normalized, conflict-free data
)

# Create crew
knowledge_crew = Crew(
    agents=[structure_detector, data_normalizer, conflict_checker, variant_generator],
    tasks=[task1, task2, task3, task4],
    process=Process.sequential,  # Or Process.hierarchical for more control
    verbose=True
)

# Run the crew
result = knowledge_crew.kickoff(inputs={
    "document_content": docling_output,
    "agent_id": agent_id
})

print(result)
```

==============================================================================
HYBRID APPROACH: CREWAI + TEMPORAL
==============================================================================

**Problem:** CrewAI can't pause for hours/days waiting for user input.

**Solution:** Hybrid orchestration

```python
# Temporal workflow
@workflow.defn
class KnowledgeWorkflow:

    @workflow.run
    async def run(self, file_id: str):
        # Step 1: Docling extraction
        document = await workflow.execute_activity(extract_with_docling, file_id)

        # Steps 2-6: CrewAI processes (fast, parallel)
        crew_result = await workflow.execute_activity(
            run_knowledge_crew,
            document_content=document.markdown,
            agent_id=self.agent_id
        )

        # Step 4 special handling: If conflicts need user input
        if crew_result.needs_user_input:
            # PAUSE Temporal workflow
            await workflow.wait_condition(
                lambda: self.conflicts_resolved,
                timeout=timedelta(days=7)
            )

            # User resolved conflicts via API
            resolution = self.conflict_resolution
        else:
            resolution = None

        # Step 7: Storage
        await workflow.execute_activity(
            store_chunks,
            chunks=crew_result.variants,
            resolution=resolution
        )


# CrewAI activity (runs inside Temporal)
@activity.defn
async def run_knowledge_crew(document_content: str, agent_id: str):
    crew = KnowledgeProcessingCrew()
    result = crew.kickoff(inputs={
        "document_content": document_content,
        "agent_id": agent_id
    })
    return result
```

**Best of both worlds:**
- ✅ CrewAI: Fast parallel agent execution (Steps 2-6)
- ✅ Temporal: Pause/resume for user input (Step 4)
- ✅ Temporal: Durable execution, retry logic, monitoring

==============================================================================
VALIDATION STEP: DO WE NEED IT?
==============================================================================

**User's question: "I'm unsure about why validation is even important"**

**Analysis:**

With CrewAI approach, validation might be redundant:

1. **Pydantic validates during structure detection** (Task 1)
   - If LLM returns invalid JSON, Pydantic catches it
   - Instructor does automatic retry

2. **Normalization handles messy data** (Task 2)
   - ftfy fixes broken Unicode
   - clean-text handles weird formats
   - Custom regex standardizes currency/dates

3. **Conflict detection checks data quality** (Task 3)
   - If data is incomplete, conflicts will appear
   - User gets notified anyway

**Recommendation: SKIP validation step** ✅

Our revised workflow:
```
Step 1: Extraction (Docling)
Step 2: Structure Detection (CrewAI Agent 1)
Step 3: Normalization (CrewAI Agent 2)
Step 4: Conflict Detection (CrewAI Agent 3)
Step 5: NL Variant Generation (CrewAI Agent 4)
Step 6: Storage (Docling Chunker + PostgreSQL)
```

**From 7 steps to 6 steps!**

Why this works:
- Pydantic = implicit validation
- Normalization = data cleaning
- Conflicts = quality check
- No separate validation needed
