KEY DIFFERENCES:
----------------
- Chakra uses "colorScheme", Mantine uses "color"
- Chakra "variant" mostly same in Mantine
- Stack direction: Chakra uses VStack/HStack, Mantine uses Stack with direction prop
- Forms: Use @mantine/form instead of react-hook-form wrappers
- Notifications: Import from @mantine/notifications instead of custom toaster
- Dark mode: Mantine has built-in useMantineColorScheme hook
