CHAKRA → MANTINE COMPONENT MAPPINGS:
-------------------------------------
Layout:
  Box → Box
  Stack → Stack
  VStack → Stack (default vertical)
  HStack → Group
  Container → Container
  Center → Center
  Flex → Flex

Typography:
  Heading → Title
  Text → Text

Forms:
  FormControl + FormLabel + Input → TextInput (has built-in label)
  Input → TextInput
  Checkbox → Checkbox
  Radio → Radio
  Select → Select
  Textarea → Textarea
  FormErrorMessage → TextInput error prop

Buttons:
  Button → Button
  IconButton → ActionIcon

Feedback:
  useToast → notifications.show (from @mantine/notifications)
  Skeleton → Skeleton
  Spinner → Loader

Overlay:
  Modal/Dialog → Modal
  Drawer → Drawer
  Menu → Menu

Navigation:
  Link (Chakra) → Anchor (or keep using TanStack router Link)

Data Display:
  Table → Table
  Card → Card / Paper
  Badge → Badge

Other:
  Divider → Divider
  Image → Image

KEY DIFFERENCES TO REMEMBER:
-----------------------------
1. Props:
   - Chakra: colorScheme="blue"
   - Mantine: color="blue"

2. Spacing:
   - Chakra: spacing={4}
   - Mantine: gap="md" or gap={16}

3. Stack Direction:
   - Chakra: <VStack> / <HStack>
   - Mantine: <Stack> / <Group>

4. Form Fields:
   - Chakra: <FormControl><FormLabel>Name</FormLabel><Input /></FormControl>
   - Mantine: <TextInput label="Name" />

5. Notifications:
   - Chakra: const toast = useToast(); toast({ title: "Success" })
   - Mantine: import { notifications } from '@mantine/notifications';
             notifications.show({ title: "Success" })

6. Dark Mode:
   - Chakra: useColorMode()
   - Mantine: useMantineColorScheme()

7. Password Input:
   - Chakra: Custom PasswordInput component
   - Mantine: <PasswordInput /> (built-in)

8. Form Validation:
   - Chakra: Usually react-hook-form
   - Mantine: @mantine/form (simpler, built-in)
