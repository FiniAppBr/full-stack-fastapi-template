Minimals Architecture & Navigation Plan
========================================

MINIMALS ARCHITECTURE OVERVIEW
-------------------------------

Navigation System:
1. /src/layouts/config-nav-dashboard.jsx  → Navigation items definition
2. /src/routes/paths.js                   → Path definitions (centralized)
3. /src/pages/dashboard/                  → Actual page components
4. /src/sections/                         → Page-specific view components

Pattern:
- Define paths in paths.js
- Reference paths in config-nav-dashboard.jsx
- Create page in /pages/dashboard/
- Create view component in /sections/

EXISTING MINIMALS PAGES WE CAN REUSE
-------------------------------------

✓ Dashboard (paths.dashboard.root)             → /dashboard
