KEY PATTERNS:
-------------

1. MICROAGENTS (from Temporal webinar):
   - Each activity = one focused agent
   - detect_intent → Gemini Flash 2.0
   - create_blocks → Gemini Flash 2.5
   - validate_blocks → GPT-4o-mini (critical)

2. MULTI-MODEL ROUTING:
   - Simple (80%) → Gemini Flash 2.0 (FREE)
   - Complex (15%) → Gemini Flash 2.5 (~$0.01/1M tokens)
   - Critical (5%) → GPT-4o-mini

3. DIGITAL TWIN:
   - One workflow per business configuration session
   - One workflow per customer conversation
   - Isolated context, no data leaks

4. CONTEXT MANAGEMENT:
   - Activities load only what they need
   - Workflow stores minimal durable state
   - Summarize after 25-30 turns (continue-as-new)
