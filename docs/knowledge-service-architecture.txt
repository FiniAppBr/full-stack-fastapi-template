THE REAL PROBLEM:
-----------------
Users upload files (PDFs, Word docs, Excel, images).
Agent needs to answer questions using that knowledge.
Must be fast, accurate, and scalable.

WHY TEMPORAL INSTEAD OF RQ/CELERY?
===================================

Temporal Advantages:
✅ Durable Execution - Workflow survives server restarts
✅ Built-in Retries - Configurable per activity
✅ Workflow History - See every step, debug easily
✅ Human-in-the-Loop - Pause for user decisions (conflict resolution)
✅ Observability - Built-in UI, metrics, tracing
✅ Already in Stack - temporalio>=1.8.0 in pyproject.toml
✅ Multi-step Orchestration - Perfect for 7-step pipeline
✅ No Redis Needed - Temporal has its own persistence

RQ/Celery vs Temporal Comparison:
┌──────────────────┬─────────────┬──────────────┐
│ Feature          │ RQ/Celery   │ Temporal     │
├──────────────────┼─────────────┼──────────────┤
│ Retry Logic      │ Manual      │ Built-in     │
│ Pause/Resume     │ No          │ Yes (Signals)│
│ History/Audit    │ No          │ Full log     │
│ Multi-step       │ Complex     │ Native       │
│ Observability    │ External    │ Built-in UI  │
│ Durability       │ Queue-based │ Event-sourced│
│ Learning Curve   │ Easy        │ Medium       │
└──────────────────┴─────────────┴──────────────┘

For a 7-step pipeline with potential user input (conflict resolution),
Temporal is the BETTER choice despite slightly higher complexity.

PART 2: TECHNOLOGY DECISIONS (RESEARCH-VALIDATED OCT 2025)
==============================================================================

ADOPTED TECHNOLOGIES:
---------------------

1. ⭐ Docling for Document Extraction (REPLACES unstructured.io)
   Why:
     - Superior accuracy (97.9% tables vs 75% for unstructured.io)
     - Better CPU performance (3.1 sec/page)
     - True open source (unstructured.io OSS has severe limitations)
     - Built-in RAG chunking (HierarchicalChunker, HybridChunker)
     - IBM-backed, production-ready
     - Comprehensive format support (PDF, Office, images, audio)
   Benchmark: 97.9% table accuracy, 100% text fidelity
   Cost: Free (MIT License)
   Install: pip install docling  # or pip install docling[easyocr]

2. ⭐ Temporal for Workflow Orchestration (REPLACES RQ)
   Why:
     - Already in dependencies (temporalio>=1.8.0)
     - Perfect for multi-step pipelines
     - Built-in retry, observability, durability
     - Handles user input (conflict resolution)
   Cost: Free (self-hosted)
   Install: Already installed

3. PostgreSQL + pgvector for Storage & Search
   Why: Unified storage, full-text + semantic search
   Cost: Free

4. GPT-4o-mini + Instructor for Micro-agents
   Why: Structured outputs, cheap ($0.0007/file)
   Cost: $0.0007 per file

5. Cohere Embed v3 Multilingual for Embeddings (v0.3+)
   Why: Best for Portuguese, $0.10/1M tokens (5x cheaper than OpenAI)
   Cost: $0.0001 per query

6. LangChain for RAG Framework
   Why: Standard, well-documented, flexible

REJECTED ALTERNATIVES:
----------------------
❌ unstructured.io - Open source version lacks chunking/embeddings
❌ RQ/Celery - Less suitable for complex multi-step workflows
❌ RAGFlow/Dify - Too general, doesn't solve our needs
❌ Pinecone - Overkill, pgvector sufficient

```python
"""
Knowledge Processing Workflow - Temporal Implementation
7-step pipeline: Extract → Detect → Validate → Conflict → Normalize → Enhance → Store
"""

from datetime import timedelta
from dataclasses import dataclass
from temporalio import workflow, activity
from temporalio.common import RetryPolicy

@dataclass
class KnowledgeProcessingInput:
    block_id: int
    file_path: str
    agent_id: int

@dataclass
class ProcessingResult:
    success: bool
    chunks_created: int
    error: str | None = None

@workflow.defn
class KnowledgeProcessingWorkflow:
    """
    Main workflow for processing uploaded knowledge files

    Steps:
    1. Extract content (Docling)
    2. Detect structure (GPT-4o-mini)
    3. Validate data (GPT-4o-mini)
    4. Check conflicts (GPT-4o-mini + user signal if needed)
    5. Normalize data
    6. Generate NL variants (GPT-4o-mini)
    7. Chunk and store
    """

    @workflow.run
    async def run(self, input: KnowledgeProcessingInput) -> ProcessingResult:
        """Execute the knowledge processing pipeline"""

        # Step 1: Extract content with Docling
        extraction_result = await workflow.execute_activity(
            extract_document_content,
            input.file_path,
            start_to_close_timeout=timedelta(minutes=5),
            retry_policy=RetryPolicy(
                maximum_attempts=3,
                initial_interval=timedelta(seconds=1),
                backoff_coefficient=2.0,
            )
        )

        if not extraction_result.success:
            return ProcessingResult(
                success=False,
                chunks_created=0,
                error=extraction_result.error
            )

        # Step 2: Detect document structure
        structure = await workflow.execute_activity(
            detect_document_structure,
            extraction_result.content,
            start_to_close_timeout=timedelta(seconds=30),
            retry_policy=RetryPolicy(maximum_attempts=2)
        )

        # Step 3: Validate data quality
        validation = await workflow.execute_activity(
            validate_document_data,
            (extraction_result.content, structure),
            start_to_close_timeout=timedelta(seconds=30)
        )

        # Step 4: Check for conflicts with existing knowledge
        conflicts = await workflow.execute_activity(
            detect_knowledge_conflicts,
            (input.agent_id, extraction_result.content),
            start_to_close_timeout=timedelta(seconds=30)
        )

        # 🔥 TEMPORAL MAGIC: Pause workflow if conflicts need user resolution
        if conflicts.needs_user_input:
            # Send notification to user
            await workflow.execute_activity(
                notify_user_conflicts,
                (input.block_id, conflicts.details),
                start_to_close_timeout=timedelta(seconds=10)
            )

            # Wait for user decision (signal)
            # Workflow pauses here - can be hours/days!
            user_decision = await workflow.wait_condition(
                lambda: self.conflict_resolution is not None,
                timeout=timedelta(days=7)  # Auto-fail after 7 days
            )

            if not user_decision:
                return ProcessingResult(
                    success=False,
                    chunks_created=0,
                    error="Conflict resolution timeout"
                )

        # Step 5: Normalize data
        normalized = await workflow.execute_activity(
            normalize_document_data,
            (extraction_result.content, structure),
            start_to_close_timeout=timedelta(seconds=30)
        )

        # Step 6: Generate natural language variants
        nl_variants = await workflow.execute_activity(
            generate_nl_variants,
            normalized.structured_data,
            start_to_close_timeout=timedelta(minutes=1)
        )

        # Step 7: Chunk and store in database
        storage_result = await workflow.execute_activity(
            chunk_and_store,
            ChunkingInput(
                block_id=input.block_id,
                markdown=extraction_result.markdown,
                chunks=extraction_result.chunks,
                nl_variants=nl_variants,
                metadata=extraction_result.metadata
            ),
            start_to_close_timeout=timedelta(minutes=2)
        )

        return ProcessingResult(
            success=True,
            chunks_created=storage_result.chunks_created
        )

    # Signal handler for conflict resolution
    @workflow.signal
    def resolve_conflict(self, decision: str):
        """User resolves conflict via API signal"""
        self.conflict_resolution = decision
```

```python
"""
Knowledge Processing Activities - Called by Temporal Workflow
Each activity is independently retryable and testable
"""

from temporalio import activity
from dataclasses import dataclass
from docling.document_converter import DocumentConverter
from docling.chunking import HierarchicalChunker
import instructor
from openai import OpenAI
from pydantic import BaseModel

# Initialize services (singleton pattern)
docling_converter = DocumentConverter()
docling_chunker = HierarchicalChunker(
    max_chunk_size=1000,
    include_metadata=True,
    preserve_tables=True
)
instructor_client = instructor.patch(OpenAI())


@dataclass
class ExtractionResult:
    success: bool
    content: str
    markdown: str
    chunks: list
    tables: list
    metadata: dict
    error: str | None = None


@activity.defn
async def extract_document_content(file_path: str) -> ExtractionResult:
    """
    Activity 1: Extract content using Docling

    Retryable: Yes (3 attempts)
    Timeout: 5 minutes
    """
    try:
        # Convert document
        result = docling_converter.convert(file_path)

        # Get markdown
        markdown = result.document.export_to_markdown()

        # Get structured JSON
        doc_json = result.document.export_to_dict()

        # Chunk document (preliminary)
        chunks = docling_chunker.chunk(result.document)

        # Extract tables
        tables = []
        for page in doc_json.get("pages", []):
            for item in page.get("children", []):
                if item.get("type") == "table":
                    tables.append({
                        "page": page.get("page_no"),
                        "html": item.get("html"),
                        "text": item.get("text")
                    })

        # Build metadata
        metadata = {
            "title": doc_json.get("description", {}).get("title"),
            "num_pages": len(doc_json.get("pages", [])),
            "has_tables": len(tables) > 0,
            "extraction_method": "docling"
        }

        # Log progress (visible in Temporal UI)
        activity.logger.info(
            f"Extracted {len(chunks)} chunks from {metadata['num_pages']} pages"
        )

        return ExtractionResult(
            success=True,
            content=markdown[:5000],  # First 5k chars for structure detection
            markdown=markdown,
            chunks=[{
                "text": c.text,
                "type": c.meta.doc_items[0].label if c.meta.doc_items else "text",
                "page": c.meta.origin.page_no if c.meta.origin else None
            } for c in chunks],
            tables=tables,
            metadata=metadata
        )

    except Exception as e:
        activity.logger.error(f"Extraction failed: {str(e)}")
        return ExtractionResult(
            success=False,
            content="",
            markdown="",
            chunks=[],
            tables=[],
            metadata={},
            error=str(e)
        )


class DocumentStructure(BaseModel):
    doc_type: str  # pricing_table, faq, policy, menu, schedule
    entities: list[str]
    confidence: float


@activity.defn
async def detect_document_structure(content: str) -> DocumentStructure:
    """
    Activity 2: Detect document structure using GPT-4o-mini

    Retryable: Yes (2 attempts)
    Timeout: 30 seconds
    Cost: ~$0.0001
    """
    activity.logger.info("Detecting document structure...")

    result = instructor_client.chat.completions.create(
        model="gpt-4o-mini",
        response_model=DocumentStructure,
        messages=[{
            "role": "user",
            "content": f"Analyze this document structure:\n\n{content}"
        }]
    )

    activity.logger.info(f"Detected: {result.doc_type} (confidence: {result.confidence})")
    return result


class ValidationResult(BaseModel):
    is_complete: bool
    missing_fields: list[str]
    errors: list[str]
    warnings: list[str]


@activity.defn
async def validate_document_data(args: tuple) -> ValidationResult:
    """
    Activity 3: Validate data quality

    Cost: ~$0.0001
    """
    content, structure = args

    result = instructor_client.chat.completions.create(
        model="gpt-4o-mini",
        response_model=ValidationResult,
        messages=[{
            "role": "system",
            "content": "Validate document data quality. Check for missing info, errors, inconsistencies."
        }, {
            "role": "user",
            "content": f"Structure: {structure.doc_type}\n\nContent:\n{content}"
        }]
    )

    return result


class ConflictReport(BaseModel):
    has_conflicts: bool
    needs_user_input: bool
    conflicts: list[dict]
    details: str
    recommendation: str  # "auto_replace", "merge", "ask_user"


@activity.defn
async def detect_knowledge_conflicts(args: tuple) -> ConflictReport:
    """
    Activity 4: Detect conflicts with existing knowledge (CRITICAL)

    Cost: ~$0.0002
    """
    agent_id, new_content = args

    # Get existing knowledge blocks
    from sqlmodel import Session, select
    from app.models.block import Block
    from app.core.db import engine

    with Session(engine) as db:
        existing_blocks = db.exec(
            select(Block).where(
                Block.agent_id == agent_id,
                Block.block_type == "knowledge",
                Block.status == "ready"
            )
        ).all()

        existing_content = "\n\n---\n\n".join([
            f"File: {b.name}\n{b.markdown_content[:500]}"
            for b in existing_blocks[:5]  # Check last 5 blocks
        ])

    if not existing_blocks:
        return ConflictReport(
            has_conflicts=False,
            needs_user_input=False,
            conflicts=[],
            details="No existing knowledge",
            recommendation="auto_accept"
        )

    result = instructor_client.chat.completions.create(
        model="gpt-4o-mini",
        response_model=ConflictReport,
        messages=[{
            "role": "system",
            "content": "Detect conflicts between new and existing knowledge. Focus on price changes, contradictions."
        }, {
            "role": "user",
            "content": f"New:\n{new_content}\n\nExisting:\n{existing_content}"
        }]
    )

    return result


@activity.defn
async def notify_user_conflicts(args: tuple):
    """Send notification to user about conflicts"""
    block_id, details = args

    # TODO: Implement notification (email, in-app, webhook)
    activity.logger.info(f"🚨 Conflict detected for block {block_id}: {details}")

    # Update block status to "needs_review"
    from sqlmodel import Session
    from app.models.block import Block
    from app.core.db import engine

    with Session(engine) as db:
        block = db.get(Block, block_id)
        if block:
            block.status = "needs_review"
            block.metadata_ = {"conflict_details": details}
            db.commit()


class NormalizedData(BaseModel):
    structured_data: dict
    cleaned_text: str


@activity.defn
async def normalize_document_data(args: tuple) -> NormalizedData:
    """
    Activity 5: Normalize and clean data
    """
    content, structure = args

    # Simple normalization (can be enhanced with LLM)
    cleaned = content.strip()

    return NormalizedData(
        structured_data={"doc_type": structure.doc_type},
        cleaned_text=cleaned
    )


class NLVariants(BaseModel):
    variants: list[str]


@activity.defn
async def generate_nl_variants(structured_data: dict) -> list[str]:
    """
    Activity 6: Generate natural language variants

    Cost: ~$0.0003
    """
    result = instructor_client.chat.completions.create(
        model="gpt-4o-mini",
        response_model=NLVariants,
        messages=[{
            "role": "system",
            "content": "Generate 3-5 natural language sentences expressing this data in different ways."
        }, {
            "role": "user",
            "content": str(structured_data)
        }]
    )

    return result.variants


@dataclass
class ChunkingInput:
    block_id: int
    markdown: str
    chunks: list
    nl_variants: list[str]
    metadata: dict


@dataclass
class StorageResult:
    chunks_created: int


@activity.defn
async def chunk_and_store(input: ChunkingInput) -> StorageResult:
    """
    Activity 7: Store chunks in database
    """
    from sqlmodel import Session
    from app.models.block import Block
    from app.models.knowledge_chunk import KnowledgeChunk
    from app.core.db import engine

    with Session(engine) as db:
        block = db.get(Block, input.block_id)
        if not block:
            raise ValueError(f"Block {input.block_id} not found")

        # Store markdown
        block.markdown_content = input.markdown
        block.metadata_ = input.metadata

        # Create chunks
        chunks_created = 0
        for idx, chunk in enumerate(input.chunks):
            knowledge_chunk = KnowledgeChunk(
                block_id=block.id,
                chunk_index=idx,
                chunk_type=chunk["type"],
                content=chunk["text"],
                page_number=chunk["page"],
                metadata_={"nl_variants": input.nl_variants} if idx == 0 else None
            )
            db.add(knowledge_chunk)
            chunks_created += 1

        # Update block status
        block.status = "ready"
        db.commit()

        activity.logger.info(f"✅ Created {chunks_created} chunks for block {input.block_id}")

        return StorageResult(chunks_created=chunks_created)
```

```python
"""
Temporal Worker - Runs workflows and activities
"""

import asyncio
from temporalio.client import Client
from temporalio.worker import Worker

from app.workflows.knowledge_workflow import KnowledgeProcessingWorkflow
from app.activities import knowledge_activities

async def main():
    # Connect to Temporal server
    client = await Client.connect("localhost:7233")

    # Create worker
    worker = Worker(
        client,
        task_queue="knowledge-processing",
        workflows=[KnowledgeProcessingWorkflow],
        activities=[
            knowledge_activities.extract_document_content,
            knowledge_activities.detect_document_structure,
            knowledge_activities.validate_document_data,
            knowledge_activities.detect_knowledge_conflicts,
            knowledge_activities.notify_user_conflicts,
            knowledge_activities.normalize_document_data,
            knowledge_activities.generate_nl_variants,
            knowledge_activities.chunk_and_store,
        ]
    )

    print("🚀 Temporal worker started - listening on 'knowledge-processing' queue")
    await worker.run()

if __name__ == "__main__":
    asyncio.run(main())
```

```python
from fastapi import APIRouter, Depends, File, HTTPException, UploadFile
from temporalio.client import Client
from app.workflows.knowledge_workflow import (
    KnowledgeProcessingWorkflow,
    KnowledgeProcessingInput
)

router = APIRouter()

# Temporal client (initialize once)
temporal_client: Client = None

async def get_temporal_client():
    global temporal_client
    if temporal_client is None:
        temporal_client = await Client.connect("localhost:7233")
    return temporal_client


@router.post("/agents/{agent_id}/knowledge/upload")
async def upload_knowledge_file(
    agent_id: int,
    file: UploadFile = File(...),
    current_user: CurrentUser = Depends(),
    db: Session = Depends(get_db),
    temporal: Client = Depends(get_temporal_client)
):
    """
    Upload knowledge file and start Temporal workflow
    """

    # Validate agent ownership
    agent = db.get(Agent, agent_id)
    if not agent or agent.user_id != current_user.id:
        raise HTTPException(status_code=404, detail="Agent not found")

    # Validate file type
    allowed_types = [
        "application/pdf",
        "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
        "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
        "application/vnd.openxmlformats-officedocument.presentationml.presentation",
        "image/jpeg",
        "image/png",
    ]

    if file.content_type not in allowed_types:
        raise HTTPException(
            status_code=400,
            detail=f"Unsupported file type: {file.content_type}"
        )

    # Validate file size (max 50MB)
    content = await file.read()
    if len(content) > 50 * 1024 * 1024:
        raise HTTPException(status_code=400, detail="File too large (max 50MB)")

    # Save file
    upload_dir = Path(f"/opt/connectai/uploads/agent_{agent_id}")
    upload_dir.mkdir(parents=True, exist_ok=True)

    file_path = upload_dir / file.filename
    with open(file_path, "wb") as f:
        f.write(content)

    # Create block with status="processing"
    block = Block(
        agent_id=agent_id,
        block_type="knowledge",
        name=file.filename,
        description=f"Uploaded {file.content_type}",
        status="processing",
        file_path=str(file_path),
        file_type=file.content_type,
        file_size=len(content)
    )
    db.add(block)
    db.commit()
    db.refresh(block)

    # 🔥 Start Temporal workflow
    workflow_id = f"knowledge-{block.id}-{int(time.time())}"
    handle = await temporal.start_workflow(
        KnowledgeProcessingWorkflow.run,
        KnowledgeProcessingInput(
            block_id=block.id,
            file_path=str(file_path),
            agent_id=agent_id
        ),
        id=workflow_id,
        task_queue="knowledge-processing"
    )

    return {
        "success": True,
        "block_id": block.id,
        "workflow_id": workflow_id,
        "status": "processing",
        "message": f"Processing {file.filename}...",
        "temporal_ui": f"http://localhost:8233/namespaces/default/workflows/{workflow_id}"
    }


@router.post("/agents/{agent_id}/knowledge/blocks/{block_id}/resolve-conflict")
async def resolve_knowledge_conflict(
    agent_id: int,
    block_id: int,
    decision: str,  # "replace", "merge", "cancel"
    current_user: CurrentUser = Depends(),
    temporal: Client = Depends(get_temporal_client)
):
    """
    Send signal to Temporal workflow to resolve conflict

    🔥 TEMPORAL MAGIC: This unblocks a paused workflow!
    """

    # Find workflow ID from block metadata
    # (stored when workflow started)

    workflow_id = f"knowledge-{block_id}-*"  # Use query to find

    # Send signal to workflow
    handle = temporal.get_workflow_handle(workflow_id)
    await handle.signal(
        KnowledgeProcessingWorkflow.resolve_conflict,
        decision
    )

    return {
        "success": True,
        "message": f"Conflict resolved with decision: {decision}"
    }
```

SEARCH STRATEGIES (By Version):
--------------------------------

v0.1: PostgreSQL Full-Text Search
-----------------------------------
Good for: 0-1000 blocks, keyword matching

```python
@router.get("/agents/{agent_id}/knowledge/search")
async def search_knowledge(
    agent_id: int,
    query: str,
    limit: int = 3,
    current_user: CurrentUser = Depends(),
    db: Session = Depends(get_db)
):
    """Search using PostgreSQL full-text"""

    results = db.exec(text("""
        SELECT
            kc.id,
            kc.content,
            kc.chunk_type,
            kc.page_number,
            b.name as source_file,
            ts_rank(
                to_tsvector('portuguese', kc.content),
                plainto_tsquery('portuguese', :query)
            ) as relevance
        FROM knowledge_chunks kc
        JOIN blocks b ON kc.block_id = b.id
        WHERE b.agent_id = :agent_id
          AND b.status = 'ready'
          AND b.is_active = true
          AND to_tsvector('portuguese', kc.content) @@
              plainto_tsquery('portuguese', :query)
        ORDER BY relevance DESC
        LIMIT :limit
    """), {"agent_id": agent_id, "query": query, "limit": limit})

    return {"query": query, "results": results.fetchall()}
```

Pros: Zero setup, fast enough (<200ms)
Cons: No semantic matching ("haircut" won't match "men's cut")

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')

def embed_text(text: str) -> list[float]:
    return model.encode([text])[0].tolist()
```

```python
for chunk in chunks:
    chunk.embedding = embed_text(chunk.content)
```

Semantic Search Endpoint:
```python
@router.get("/agents/{agent_id}/knowledge/search-semantic")
async def search_semantic(
    agent_id: int,
    query: str,
    limit: int = 3,
    db: Session = Depends(get_db)
):
    """Semantic search with embeddings"""

    query_emb = embed_text(query)

    results = db.exec(text("""
        SELECT
            kc.content,
            b.name as source_file,
            1 - (kc.embedding <=> :query_emb) as similarity
        FROM knowledge_chunks kc
        JOIN blocks b ON kc.block_id = b.id
        WHERE b.agent_id = :agent_id
          AND b.status = 'ready'
        ORDER BY kc.embedding <=> :query_emb
        LIMIT :limit
    """), {"agent_id": agent_id, "query_emb": query_emb, "limit": limit})

    return {"query": query, "results": results.fetchall()}
```

Pros: Semantic understanding, better accuracy
Cons: Requires embeddings (slower processing), more complex


v1.0: Hybrid Search (Best Accuracy)
------------------------------------
Combine keyword (30%) + semantic (70%)

```python
@router.get("/agents/{agent_id}/knowledge/search-hybrid")
async def search_hybrid(agent_id: int, query: str, limit: int = 3):
    """Hybrid: 70% semantic + 30% keyword"""

    query_emb = embed_text(query)

    results = db.exec(text("""
        SELECT
            kc.content,
            b.name as source_file,
            (
                0.7 * (1 - (kc.embedding <=> :query_emb)) +
                0.3 * ts_rank(
                    to_tsvector('portuguese', kc.content),
                    plainto_tsquery('portuguese', :query)
                )
            ) as score
        FROM knowledge_chunks kc
        JOIN blocks b ON kc.block_id = b.id
        WHERE b.agent_id = :agent_id
          AND b.status = 'ready'
        ORDER BY score DESC
        LIMIT :limit
    """), {"agent_id": agent_id, "query_emb": query_emb, "query": query, "limit": limit})

    return {"results": results.fetchall()}
```

Pros: Best accuracy (>90%)
Cons: Most complex, highest compute
