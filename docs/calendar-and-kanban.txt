Calendar & Kanban Implementation Analysis

DIFFICULTY ESTIMATE
-------------------

| Component       | Effort   | Complexity | Notes                                      |
|-----------------|----------|------------|--------------------------------------------|
| Calendar Model  | 1-2 hrs  | Low        | id, agent_id, title, start, end, color     |
| Calendar API    | 2-3 hrs  | Low        | CRUD endpoints, match frontend format      |
| Calendar Tool   | 1 hr     | Low        | Wire to model                              |
| Kanban Model    | 2-3 hrs  | Medium     | Column + Task tables with ordering         |
| Kanban API      | 4-5 hrs  | Medium     | Many endpoints, drag-drop state mgmt       |
| Kanban Tool     | 1 hr     | Low        | Wire to model                              |

Total: ~12-15 hours


RECOMMENDATION
--------------

Start with Calendar:
- Simpler model
- Faster win
- Immediately useful for appointment booking

Kanban is more complex:
- Two related tables (columns + tasks)
- Position/ordering logic for drag-drop
- Many endpoint variations
